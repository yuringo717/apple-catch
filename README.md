# 🍎 りんごキャッチ！

木から落ちてくるりんごをカゴで受け止める、レトロなドット絵ミニゲームです。
たまに落ちてくる**むし**を拾ってしまうとライフが減ります。

**HTML1ファイルだけで完結**しています。ダウンロードしてダブルクリックするだけで遊べます（インストール不要・オフラインOK・スマホ対応）。

## 遊びかた

- **カゴを動かす** … マウス／指でなぞる、または `←` `→` キー
- **はじめる／もう一度** … 画面タップ、または `Space` キー
- **音のオン/オフ** … 左下のスピーカーボタン、または `M` キー

| アイテム | 効果 |
|---|---|
| 🍎 りんご | +10 |
| ✨ きんりんご | +50（キラキラ演出つき） |
| 🐛 むし | −30 ＆ ライフ −1 |
| 💗 ハート | ライフ +1（Lv.3以降、ライフが減っているときだけ出現） |

りんごを落としてもライフは減りませんが、**コンボが途切れます**。

## レベルの仕組み

りんごを **12個キャッチするごとにレベルアップ**。上がるほど忙しくなります。

| 要素 | 変化 |
|---|---|
| 落下速度 | Lv.1 の 132 から、1レベルごとに +21 |
| 出現間隔 | 0.92秒 から徐々に短く（最短 0.34秒） |
| むしの割合 | 10% から、1レベルごとに +2.8%（最大 42%） |
| ゆらゆら落下 | Lv.4 から、一部のアイテムが左右に揺れる |
| 同時落下 | Lv.6 から、2個同時に落ちることあり |
| BGMのテンポ | レベルに合わせて少しずつ速くなる |

**コンボ**は連続キャッチ数です。5連ごとにスコア倍率が上がり、最大 **x5**。
金りんごをコンボ中に取ると一気に伸びます。ハイスコアはブラウザに保存されます。

## 技術メモ

外部ライブラリ・画像・フォントファイルを一切使っていません。すべて Canvas で描画しています。

- **ドット絵の作り方** … ゲーム画面を 160×240 の低解像度バッファに描いてから、
  ニアレストネイバーで3倍に拡大しています。これで背景もキャラもまとめてカクカクになります。
- **ドット文字の作り方** … 文字を小さいサイズで一度描き、アルファ値を2値化して
  アンチエイリアス（にじみ）を消してから拡大しています。この方式なら日本語もドット文字になります。
- **サウンド** … Web Audio API の矩形波・三角波によるチップチューン。
  効果音もBGM（8小節ループ）もすべてコードで生成しています。
